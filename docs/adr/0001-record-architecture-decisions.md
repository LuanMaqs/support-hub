# ADR-0001: Record architecture decisions

- **Status:** accepted
- **Date:** 2026-10-27

## Context
Choices such as Flow vs Apex or queue design are easy to forget and hard to explain later.

## Decision
We record significant decisions as short ADRs in `docs/adr/`, using `0000-template.md`.

## Consequences
New joiners and reviewers can see the reasoning behind the design. Writing an ADR takes a few minutes per decision.
